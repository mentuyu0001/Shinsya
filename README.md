## ゲーム概要
このゲームの最大の特徴は、**「芯車（しんしゃ）」** と呼ばれる非常に不安定な乗り物です。
プレイヤーは「カスタムフェーズ」と「プレイフェーズ」を繰り返してステージ攻略を目指します。

### 1. 芯車カスタムフェーズ
70×50マスのグリッド上に「ブロック」を自由に配置し、マシンのバランスを調整します。

![ae46aaf3cca7544c9efa0f77ef4e8d8e](https://github.com/user-attachments/assets/e4a57b9b-36c2-4fad-ab95-343604e77459)


* **トレードオフの設計**:
    * ブロックを多く置く → **安定するが、重くて遅い**
    * ブロックを減らす → **速いが、転倒しやすい**

<img width="794" height="688" alt="image" src="https://github.com/user-attachments/assets/37b85746-f838-4c67-831c-66b2769529e4" />

*(左：基本形、右：ピラミッド型・羽型・丸型などのカスタム例)*

重心の位置や形状を工夫し、**「自分だけの最強の芯車」** を作り出す試行錯誤が楽しめます。

### 2. ゲームプレイフェーズ
作成した芯車で障害物だらけのステージを走破します。
ジャンプ時の衝撃や坂道でバランスを崩さないよう、繊細な操作と事前のカスタマイズが重要になります。

## 操作方法

| フェーズ | アクション | キー操作 / マウス操作 |
|:-:|:-:|---|
| **共通** | リセット | `R` |
| | タイトルへ | `U` |
| **カスタム** | ブロック配置 | 左クリック（ペンモード） |
| | ブロック削除 | 左クリック（消しゴムモード） |
| | ゲーム開始 | 画面下の「これで開始！」ボタン |
| **プレイ** | 前進 | `→` or `右クリック` (長押し) |
| | 後退 | `←` or `左クリック` (長押し) |
| | ジャンプ | `Space` |

## 制作背景とコンセプト
本作品は、CESA賞のテーマ「図工、美術、音楽の授業で活用できるような作品」に着想を得て制作されました。

小学校学習指導要領（図画工作編）にある「思考力・判断力・表現力」等の能力育成を目的とし、以下のサイクルをデザインの核としています。

1. **思考・判断**: 「どうすれば倒れないか？」を考え、ブロックを配置する。
2. **表現・実験**: 実際に走らせてみる。
3. **達成感**: 自分の工夫でクリアする喜びを感じる。

この「試行錯誤の楽しさ」を通じて、プレイヤーの創造性を刺激することを目指しました。

## 技術スタック・開発の工夫
* **言語**: C++
* **フレームワーク**: OpenSiv3D
* **開発期間**: 約2週間（ゲームジャム期間）

**設計上のポイント:**
短期間での開発とバグ修正を効率化するため、スクリプトを機能ごとに分割し、インターフェースを活用した疎結合な設計を採用しました。また、ターゲット層（小学生）を意識し、操作説明を常に画面に表示するUI設計を行っています。
